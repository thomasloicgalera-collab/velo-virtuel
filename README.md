# Vélo virtuel 🚴

Jeu de vélo virtuel en 3D pour home trainer (type Zwift), qui tourne directement dans le navigateur.

## Pour rouler

Ouvre le lien du jeu dans **Google Chrome** ou **Microsoft Edge**, sur ordinateur (Mac ou PC).
Safari et Firefox ne savent pas se connecter en Bluetooth au home trainer.

Au démarrage, connecte ton home trainer (compatible FTMS : Wahoo, Tacx, Elite…), ton capteur de
puissance ou ta ceinture cardio, ou clique sur « Passer cette étape » pour visiter.

Le lien affiche toujours la dernière version : pas besoin de retélécharger quoi que ce soit.
Si une nouveauté n'apparaît pas, recharge la page avec Cmd+Maj+R (Mac) ou Ctrl+Maj+R (PC).

Le mode d'emploi complet est dans [LISEZ-MOI.txt](LISEZ-MOI.txt).
